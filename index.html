THE BEGINNING

The first server address

The server originally used nojusy.aternos.me. Nojukas later decided to turn the server into an SMP. The owner later wanted to turn it into an SMP.

Mining SMP is born

The server address changed to miningsmp.aternos.me, giving the project its Mining SMP identity.
